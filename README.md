# EBG+

EBG+ is a cinematic streaming-platform prototype for EBG.

## What this build includes (Phase 1 foundation)

- Logged-out marketing landing page
- Authentication flows (sign in, create account, forgot/reset password)
- Profile selector with manage profiles
- Streaming home with hero banner + dynamic content rails
- Heartspell House flagship show page with episodes and cast
- Video playback page with resume progress and next-episode flow
- Continue Watching and My List (profile-scoped)
- Search, notifications, settings
- Casting & submissions page (21+ guard)
- Secure role-gated **EBG Studio** admin surface with basic CMS controls
- Mobile bottom navigation and responsive layout

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
